# 올팍 Go! (Olpark Go!)

**AI 기반 올림픽공원 공연·날씨 연계 주차 혼잡도 예측 및 맞춤 방문 가이드**

> 2026년도 공공데이터 활용 경진대회(한국체육산업개발(주)) 출품작

서비스 주소: **https://davidok7.github.io/olpark-go/**

## 무엇을 하는 서비스인가

올림픽공원은 KSPO DOME(14,594석), 티켓링크 라이브 아레나(5,003석), 올림픽홀(2,454석), 우리금융아트홀(1,184석) 등 5개 공연장에서 연중 공연이 열리는 곳입니다. 공연이 있는 날에는 시작 2시간 전부터 주차장이 포화되고 주변 도로가 정체되지만, 기존에 공개된 주차 정보는 **지금 몇 대가 주차되어 있는지(3개 문 합계)** 와 **주말 한정·전 시간대 동일한 예상 이용률** 뿐이어서 "내가 갈 시간에 얼마나 붐빌지, 어느 문으로 들어가야 하는지"는 알 수 없습니다.

올팍 Go!는 방문 날짜·시간대·공연장·날씨를 입력하면

1. **시간대별 예상 주차 점유율**(여유/보통/혼잡/만차)과 24시간 차트를 보여주고,
2. **12개 주차구역별 예상 점유율·입차 대기시간·공연장까지 도보 시간**을 표로 제시하며,
3. 공연장 앞 구역이 만차이면 **한 블록 떨어진 구역**을 추천하고, 주차가 어려우면 **올림픽공원역(5·9호선)·한성백제역(9호선)·몽촌토성역(8호선)** 가운데 도보 시간을 고려한 우회 동선을 안내하며,
4. **공연 전 90분·공연 후 60분 맞춤 산책·휴식 코스**를 제안합니다.

실시간 주차현황은 한국체육산업개발이 공개한 API(`https://www.ksponco.or.kr/online/main/parkingorsApi.do?apiKey=PARKING21803504`)를 브라우저에서 직접 호출해 표시합니다(CORS 허용). 응답이 없으면 예측 모델 값으로 대체됩니다.

## 예측 방식

```
점유율(h) = min(100, (기본수요(h) + 공연수요(h) × 날씨계수) ÷ 전체 주차면 × 100)
공연수요(h) = Σ (관람객수 × 자가용분담률 0.22 ÷ 평균승차인원 2.8)
              × 도착분포(공연 3시간 전 ~ 10분 후) − 출차분포(종료 후 90분)
기본수요(h) = 2025년 연계데이터의 시간대별 입차 구성(주중·금·토·일 24시간 곡선)
날씨계수   = 맑음 1.00 / 비 1.14 / 눈 1.26
구역점유율 = (구역면 × 기본점유 + 공연차량 × 공연장 근접도 가중치) ÷ 구역면
대기시간   = f(구역점유율) : 70% 미만 0분 · 70~85% 선형 · 85% 이상 급증
```

프로토타입의 시간대별 기본 곡선과 계수는 공개 데이터의 구성 항목을 기준으로 설계한 **잠정값**이며, 2025년 원 데이터 전체를 확보하는 대로 회귀 보정합니다.

## 실행

빌드 도구가 필요 없습니다. `index.html`을 브라우저로 열면 동작합니다(정적 HTML·CSS·JavaScript).

```
index.html   화면 구조
style.css    스타일(반응형)
data.js      구역·공연·데이터 정의
app.js       예측 엔진과 화면 렌더링
```
